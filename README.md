# LASTBOT — Docker-окружение (production)

Готовое окружение для запуска статического сайта в контейнере Nginx.

> **Пошаговая инструкция развёртывания и заливки на GitHub —
> в файле `ИНСТРУКЦИЯ_ПО_РАЗВЕРТЫВАНИЮ.txt`** (рядом с этим README).

## Структура

```
project/
├── Dockerfile              # образ на базе nginx:alpine (+ nodejs из apk)
├── docker-compose.yml      # сервис web, порт 8080 -> 80, volume ./data
├── docker-entrypoint.sh    # запускает nginx и админ-бэкенд вместе
├── nginx/
│   └── nginx.conf          # gzip, кэш, SPA-fallback, прокси /admin и /api/, безопасность
├── public/                 # файлы сайта (index.html, assets/, правовые страницы)
├── server/
│   ├── admin-server.mjs    # админ-бэкенд: авторизация и хранение контента (Node, без зависимостей)
│   └── admin/              # веб-панель /admin (HTML/CSS/JS)
├── data/                   # создаётся при запуске: content.json и secret.key (volume)
└── README.md
```

## Требования

- Docker Engine (20.10+) или Docker Desktop с плагином `docker compose`.
- Папка `public/` рядом с `docker-compose.yml` (сайт целиком, включая `assets/`).

## Сборка и запуск

```bash
docker-compose build
docker-compose up -d
```

Проверка: откройте **http://localhost:8080**

Статус и логи:

```bash
docker-compose ps
docker-compose logs -f web
```

Остановка:

```bash
docker-compose down          # остановить контейнер
docker-compose down -v       # остановить и удалить тома (если появятся)
```

## Обновление сайта

```bash
# после изменения файлов в public/ или конфига Nginx:
docker-compose build
docker-compose up -d
```

**Важно про кэш**: статика отдаётся с `Cache-Control: public, immutable` —
браузеры не перепроверяют её до истечения суток. Поэтому при каждом
изменении файлов в `public/` увеличивайте версию в адресах ассетов:
в `index.html` (и правовых страницах) у `style.css`, `i18n.js`, `main.js`
поменяйте `?v=2` → `?v=3` и т.д. Иначе посетители увидят старую версию
до конца кэша.

Для разработки без пересборки образа раскомментируйте том
`./public:/usr/share/nginx/html:ro` в `docker-compose.yml` — изменения
файлов будут видны сразу (после `docker-compose up -d`).

## Деплой с GitHub

**Первая настройка (один раз):**

1. Локально: создайте `.env` из `.env.example` и задайте свой `ADMIN_PASS`
   (`.gitignore` уже не пустит `.env` и `data/` в репозиторий).
2. Залейте проект в приватный репозиторий:

   ```bash
   git init
   git add .
   git commit -m "LASTBOT"
   git remote add origin git@github.com:ВАШ-АККАУНТ/lastbot.git
   git push -u origin main
   ```

3. На VPS: склонируйте репозиторий, создайте `.env` и запустите:

   ```bash
   git clone git@github.com:ВАШ-АККАУНТ/lastbot.git /opt/lastbot
   cd /opt/lastbot
   cp .env.example .env   # затем отредактируйте ADMIN_PASS
   ./deploy.sh
   ```

**Обновления:**

- С Windows-машины: `.\deploy.ps1 -Server root@ВАШ-СЕРВЕР -Path /opt/lastbot`
  (пушит код и запускает деплой на VPS по SSH).
- Или прямо на VPS: `cd /opt/lastbot && ./deploy.sh`.

`deploy.sh` делает: `git pull` → резервную копию `data/` → сборку образа →
перезапуск → проверки `/healthz` и `/api/news`. Сборка не запустится без
`.env` с `ADMIN_PASS` — это осознанная защита от скомпрометированного
пароля по умолчанию.

## Админ-панель

Веб-панель для редактирования всего контента сайта: **http://localhost:8080/admin/**

- Логин / пароль по умолчанию: `ta-admin` / `142536Mainkey`.
- **Обязательно смените пароль перед публикацией** — пароль по умолчанию
  известен. Задаётся переменными окружения в `docker-compose.yml`
  (`ADMIN_USER`, `ADMIN_PASS`) или прямо в `server/admin-server.mjs`.
- Редактируется: главный экран, преимущества, функции, тарифы, новости,
  промокоды, FAQ, CTA-баннер и контакты. Кнопка «Сохранить» публикует
  изменения сразу — сайт перечитывает контент при каждой загрузке страницы.
- «Сбросить контент» возвращает заводские значения.
- Все правки хранятся в `./data/content.json` (volume), секрет сессии —
  в `./data/secret.key`. Удаление папки `data/` сбрасывает панель к заводскому
  состоянию.
- Авторизация серверная: пароль сверяется на бэкенде, сессия — подписанный
  HMAC-токен в httpOnly-куке (12 часов), попытки входа ограничены
  (8 за 10 минут с одного IP). GET `/api/content` публичный (его читает сам
  сайт), изменения требуют входа.
- Под кнопкой «Войти» есть строка статуса: она показывает состояние панели
  (зелёным) и любую ошибку входа/загрузки (красным, с причиной).
- Если после входа панель не открывается: жёсткое обновление **Ctrl+F5**
  или режим инкогнито — ассеты панели версионируются и отдаются без кэша,
  поэтому повторный заход сработает.

## Диагностика

- `http://localhost:8080/healthz` — живость контейнера (вернёт `ok`),
  используется HEALTHCHECK образа.
- `http://localhost:8080/api/content` — публичный JSON контента сайта
  (его читает главная страница; отдаётся с `Cache-Control: no-store`).
- `http://localhost:8080/admin/` — вход в панель управления.
- Логи: `docker-compose logs -f web` (nginx пишет в access.log,
  админ-бэкенд — в stdout контейнера).

## Языки сайта

Сайт переведён на 8 языков: русский, английский, испанский, немецкий,
французский, португальский, китайский и арабский (с RTL-раскладкой).

- Переключатель — в шапке (иконка глобуса). Выбор сохраняется в браузере;
  при первом заходе язык определяется по языку браузера.
- Все переводы лежат в `public/assets/js/i18n.js` (словарь `window.LB_I18N`):
  контент всех секций, строки интерфейса и адреса новостных фидов по локали.
- Правки из админ-панели применяются к **русской** версии; остальные языки
  показывают встроенные переводы. Чтобы поправить перевод — редактируйте
  `public/assets/js/i18n.js`.

## Что уже настроено в Nginx

- **gzip** для CSS, JS, JSON, SVG, текста.
- **Кэш 1 день** с `Cache-Control: public, immutable` для статики
  (css, js, изображения, шрифты, иконки). HTML отдаётся с `no-cache`,
  чтобы обновления страниц не зависали в кэше.
- **SPA-fallback**: любой неизвестный путь отдаёт `index.html`
  (плюс `error_page 404`).
- **Заголовки безопасности**: `X-Content-Type-Options: nosniff`,
  `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy`,
  `Permissions-Policy`. `server_tokens off`.
- `client_max_body_size 1m`.
- Проверка живости контейнера: `GET /healthz` (используется HEALTHCHECK).

## Примечания

- Сайт полностью статический: лента новостей, промокоды и оплата работают
  на клиенте, дополнительных серверных настроек не требуется.
- Новости: приоритетный источник — официальное сообщество DLS ВКонтакте
  (vk.ru/doomsday_last_survivors_ru), ниже — свежая лента Google News.
  Лента приходит через собственный прокси бэкенда `/api/news` (без сторонних
  CORS-сервисов), кэшируется на сервере 15 минут. Список постов VK лежит
  в `public/assets/js/main.js` (массив `VK_NEWS`) — добавляйте туда новые
  посты сообщества. Лента обновляется автоматически раз в 4 часа.
- Шрифты подгружаются с Google Fonts; все внешние запросы уходят из браузера
  пользователя, а не с сервера.
- Порт хоста можно сменить в `docker-compose.yml`: `"8080:80"` →
  например `"80:80"` (понадобятся права на привилегированный порт).
- Если порт 8080 занят, измените левую часть маппинга порта.

## Бизнес-системы (новое)

- **Калькулятор тарифов**: ползунок 1–30 ботов; маржинальные блоки
  (пакеты точно: 10 ботов = $20, 20 = $35, 30 = $55; блоки 1–10 по $2.00,
  11–20 по $1.50, 21–30 по $2.00, промежуточные количества — плавно,
  без «просадок» цены); срок 1/3/6/12 мес со скидками 0/10/15/25 %
  (коэффициенты 1.0/2.7/5.1/9.0), цена в $ и ₽, «вы экономите».
  Конфиг: `pricing.botPrices` (блоки) и `pricing.periods` в content.json.
  Конфиг: `pricing.botPrices` и `pricing.periods` в content.json.
- **Акции**: раздел «Акции» в админке (data/promotions.json).
  Типы: percent / fixed / bots-gift; условия: сроки, мин/макс ботов,
  даты, лимит использований. Баннер показывается над калькулятором.
- **Триал**: кнопка «Попробовать бесплатно» в hero → POST /api/trial
  (7 дней, 5 ботов; TRIAL_DAYS/TRIAL_BOTS), заявки в data/trials.json,
  реферальный код выдаётся автоматически, уведомление в Telegram.
- **Реферальная программа**: код альянса (8 символов,
  crypto.randomBytes); приведённый альянс = их боты на 1 месяц
  бесплатно + 10% суммы покупки (REFERRAL_COMMISSION_PERCENT).
- **Кэшбэк**: 10% от числа купленных ботов бото-месяцами
  (CASHBACK_PERCENT) при каждой покупке.
- **Дашборд**: страница /dashboard — ввод кода альянса →
  GET /api/dashboard?code=… (баланс, история покупок, рефералы).
- **Отзывы** и **топ альянсов**: content.json (`testimonials`,
  `stats.topAlliances`), редактируются в админке.
- **Калькулятор экономии времени** — чистый JS, без бэкенда.

## Новые данные в data/

- `trials.json` — заявки на триал.
- `balances.json` — бото-месяцы, кэшбэк, покупки, рефералы альянсов.
- `referrals.json` — коды альянсов и связи «кто кого привёл».
- `promotions.json` — акции (CRUD через админку).

## Новые API

- `POST /api/trial` — заявка на триал (публичный, rate-limit 5/час/IP).
- `GET /api/dashboard?code=…` — баланс альянса (публичный, код-секрет).
- `GET /api/pricing` — botPrices, periods, активные акции, курс ₽.
- `GET /api/promocodes/active?bots=N` — активные промокоды с условиями.
- `POST /api/purchase` — подтверждение покупки (кэшбэк + рефералы).
- `POST /api/referral/generate`, `POST /api/referral/apply` — рефералы.
- `GET/PUT /api/promotions`, `GET/PUT /api/balances`,
  `GET/PUT /api/trials`, `GET /api/referrals` — админка (auth).

## Новые переменные .env

`TRIAL_DAYS=7`, `TRIAL_BOTS=5`, `REFERRAL_COMMISSION_PERCENT=10`,
`CASHBACK_PERCENT=10`, `RUB_RATE=85` (курс $→₽ для отображения цен).
